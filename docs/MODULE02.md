# Module 02：综述格局、最新研究与自动视角选择

## 跨运行时状态驱动

DeepSeek Harness、Kiro Crew和Codex在创建Module 02后都必须重复调用`module02-next`。该命令返回唯一下一动作及`blocking_user_input`。当值为`false`时，Agent必须执行动作并再次调用，不得把中间进度作为最终输出。只有真实机构登录、已保存检查点的提供方失败等人类或外部阻塞可以暂停。视角选择不再阻塞用户。

Python在`perspectives_ready`之前拒绝渲染最终报告，在研究分类正式完成之前拒绝保存视角。Module 01研究查询和Module 02研究补检只接受冻结`query_id`；Module 02综述查询由Python从冻结的直接主题查询确定性派生。

## 入口

Module 01由Agent保存最终建议。只有`recommended`允许创建或恢复Module 02；`reframe_required`、`insufficient_evidence`和`not_recommended`均终止当前工作流。数据库门禁不接受缺失决定。

## 阶段 A：相关综述

优先检索并纳入同时锚定全部核心关键词的完整主题综述。若没有，必须明确报告未发现完整主题综述，再纳入全部最高相关的合格邻近综述，最多5篇。邻近综述必须显示匹配关键词，不能表述成完整主题综述；同时完成全文状态、原因、结构、未来趋势、TrendClaim、时间锚点、后续研究比较和视角分析。

OpenAlex负责题名与摘要范围的元数据发现和引用次数快照，并通过游标分页尽可能取全；单条查询最多10页、每页100条，超出时标记截断。Nature Index身份只读取Module 01附加的本地目录快照。

全文获取顺序为合法开放版本优先。没有开放PDF时保存`login_required`并显示机构访问选择。用户只在学校官方页面或自己的普通浏览器中登录；Agent不得接触账号、密码、MFA或Cookie。只有注册的合法PDF可支持全文证据。

## 阶段 B：锚点后研究

选择最新纳入综述作为时间锚点。研究窗口为其发表日期前6个日历月至当前系统日期。先复用Module 01论文，再仅对Python标记为`supplement`的冻结查询补检。

每篇研究论文分类为：

- `trend_consistent`：直接实现或验证综述明确提出的趋势；
- `trend_extension`：实质扩展该趋势；
- `new_direction`：相关但未被综述趋势覆盖；
- `review_candidate`：实际为综述、调查、系统综述或其他证据综合，但被研究补检发现；
- `excluded`：语义复核后不相关。

出现`review_candidate`时，必须在研究比较完成前调用`promote-research-reviews`批量转回综述筛选。Python会把它们从研究列表移除，重置受不完整综述基线影响的TrendClaim、时间锚点和研究分类，并保留原始检索证据。重新筛选完整综述集合后，才能登记用户提供的合法PDF并继续全文分析。

没有相关综述时使用Module 01两年窗口，相关研究作为`new_direction`，并继续生成可能的首篇主题综述视角。

## 阶段 C：候选视角和自动选择

生成3–5个候选视角。每个视角必须提供研究证据、与已有综述的相同点和实质差异、建议边界、重叠风险、选择理由，以及三个0–100评分：

- 差异性：与已有完整主题或邻近主题综述的组织方式、范围和结论距离；
- 完整性：现有证据能否支持边界清楚且端到端完整的综述；
- 成熟性：概念、方法、比较和开放问题是否足以形成综合判断。

Python计算`0.40 × 差异性 + 0.30 × 完整性 + 0.30 × 成熟性`，最高分视角自动成为`selected_for_module03`；同分时选择较低的持久rank。调用`select-best-perspective`会保存评分依据并立即创建或恢复Module 03 run。Agent不向用户展示选择问题，也不等待回复。

## 输出与边界

最终报告包括逐篇综述档案、锚点后研究分类、3–5个视角及其评分，以及Agent自动选择结果。未选视角保留为SQLite审计分支。Module 02随后立即进入Module 03，但自身不得生成大纲、正文、图表或投稿文件。
