# Module 04：约15,000字综述写作与Markdown导出

## 入口

用户在Module 03选择`1. 满意，冻结大纲`后，最新版大纲状态变为`outline_approved`，系统自动创建或恢复Module 04 manuscript run。未批准的大纲不能进入本模块。

## 写作目标

- 默认语言：中文；
- 目标正文：约15,000字；
- 接受区间：13,500–16,500字；
- 字数口径：去除空白、Markdown符号和内部引用标记后的正文字符；
- 不计入：参考文献和图表位置说明；
- 输出：完整Markdown综述草稿。

## 分节写作

Python根据冻结大纲建立Abstract和每个一级章节的写作计划，按章节复杂度分配目标字数。`module04-next`每次最多返回两个待写章节。Agent按冻结大纲中的目的、逻辑、问题、证据和衔接撰写，并通过`import-manuscript-section`保存。

Module 04只使用Module 02已持久化证据，不新增检索。草稿使用`[@evidence_id]`内部引用标记；Python验证后在最终稿中替换成编号引用，用户不会看到裸ID。

## 图表位置

本MVP不生成图片二进制。Agent为需要的图表提交结构化占位信息，包括标题、论证用途、具体内容和来源证据。最终Markdown显示：

```text
[图 N 置于此处：标题]
[表 N 置于此处：标题]
```

并附上建议内容和编号证据来源。

## 字数修订

所有章节完成后，`module04-next`计算正文总字数。超出13,500–16,500时返回`revise_manuscript_length`及逐节目标/实际字数，Agent修改后重新导入。只有达到范围才能组装。

## 最终组装

`assemble-module04`确定性执行：

1. 按冻结大纲顺序合并摘要和章节；
2. 把内部引用转换为编号引用；
3. 插入图表位置；
4. 根据SQLite元数据生成参考文献；
5. 写入`outputs/final/<module04_run_id>-review.md`；
6. 保存文件SHA-256、字数、图表数量和完成状态；
7. 返回`MVP任务完成`。

## 当前MVP终点

Module 04完成后不再运行其他模块。稿件是需人工科学审阅和编辑的草稿，不应未经核验直接投稿。
