# Module 04：基于冻结大纲的直接完整稿件生成

## 入口

用户在Module 03选择`1. 满意，冻结大纲`后，系统创建或恢复Module 04。未批准大纲不能进入。

## 为什么采用直接生成

Module 04由当前根Agent在同一个连续上下文中生成完整稿件，不再把不同一级章节分配成独立写作批次，也不再执行单独的Module 05自我评价。这样能够让Agent同时掌握全文结构、证据、术语、过渡和结论，减少章节拼接、重复限制和全局主线弱化。

## 输入

- Module 03冻结的大纲及其全部层级；
- Module 02所选综述视角；
- Module 02全部相关、已纳入证据；
- 已保存的证据限制和全文状态。

Module 04可以使用Module 02范围内的其他相关证据补充内容，不局限于少量节点证据ID，但不能改变冻结视角或发起新检索。

## 输出要求

- 中文完整综述；
- 目标约15,000字；
- 接受区间13,500–16,500字；
- 包含摘要、关键词、所有冻结编号标题和参考文献；
- 至少一处图位置和一处表位置；
- 不显示内部证据ID；
- 图表位置说明具体展示内容，不生成图片二进制。

## 状态

```text
write_complete_manuscript
→ export_markdown
→ mvp_complete
```

Agent通过`import-manuscript`一次提交完整稿件。Python验证字数、全部冻结标题、证据范围、图表位置和内部ID，然后通过`export-module04`写入：

```text
outputs/final/<module04_run_id>-review.md
```

## 当前MVP终点

Module 04完成后任务结束。当前没有Module 05，也不导出DOCX。最终稿仍需用户自行开展科学审阅和投稿编辑。
